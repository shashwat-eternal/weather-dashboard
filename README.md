# 🌦️ Weather Dashboard

A premium **Weather Analytics Dashboard** built using **Python, Streamlit, Open-Meteo API, Pandas, and Matplotlib**.  
The application provides **real-time weather insights, 24-hour forecasts, 7-day weather trends, interactive charts, and downloadable forecast data** through a clean dashboard-style interface.

---

## 🚀 Features

### 🌍 Current Weather Overview
- Search weather by city name
- Displays:
  - Current temperature
  - Feels like temperature
  - Humidity
  - Wind speed
  - Surface pressure
  - Precipitation
  - Weather condition with icon

### ⏱️ 24-Hour Forecast
- Hourly weather forecast for the next 24 hours
- Includes:
  - Temperature
  - Humidity
  - Rain probability
  - Wind speed

### 📅 7-Day Forecast
- Weekly forecast with:
  - Maximum temperature
  - Minimum temperature
  - Rainfall / precipitation
  - Weather condition icons
  - Daily summary cards

### 📈 Weather Analytics
Interactive weather analytics using **Matplotlib**:
- **7-day max/min temperature trend**
- **7-day precipitation chart**
- **24-hour temperature trend**
- **24-hour wind speed chart**

### 📄 Forecast Data Export
- Download forecast data as **CSV**
- Includes forecast metrics for further analysis or reporting

### 🎨 Premium UI
- Modern **dashboard-style layout**
- Dark theme with premium cards and sections
- Streamlit-based responsive weather analytics experience
- Quick city selection from sidebar
